# 🌤️ LocalWeather - iOS Weather App

A beautiful, feature-rich weather app built with SwiftUI for iOS.

## ✨ Features

- **Real-time weather** with beautiful animations
- **5-day forecast** with hourly details
- **Interactive map** view
- **Search** any city worldwide
- **Air quality** index
- **UV index** monitoring
- **Precipitation** charts
- **Beautiful UI** with glass morphism effects
- **Animated backgrounds** based on weather conditions


## 🛠️ Technologies Used

- SwiftUI
- MapKit
- CoreLocation
- Combine framework

## 🚀 How to Run

1. Clone the repository
2. Open `LocalWeather.xcodeproj` in Xcode
3. Select your target device (simulator or physical iPhone)
4. Press `Cmd + R` to build and run

## 📋 Requirements

- iOS 15.0+
- Xcode 14.0+
- Swift 5.5+
